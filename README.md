## 🏗️ Architecture & Coding Standards

My software design principles focus on scalability, maintainability, and clean code:

- 📐 **Decoupled Architecture**: Modular client-server separation with strict layer isolation (`Controllers`, `Services`, `Models`, `Routes/Middlewares`).
- ⚡ **Type-Safe Development**: Leveraging TypeScript on the frontend and strongly-typed C# / ASP.NET Core on the backend for compile-time safety and self-documenting code.
- 🔄 **Predictable State Handling**: Centralized state management using Next.js & Redux Toolkit thunks with clean side-effect handling.
- 🔍 **SEO & Performance**: Server-Side Rendering (SSR) & Static Site Generation (SSG) in Next.js, metadata optimization, Open Graph, and JSON-LD structured data.
- 🛡️ **Security & Defensive Coding**: Robust DTO validation, input sanitization, JWT authorization, and protected route guards.
